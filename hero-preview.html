Three signal fields

Each sits behind the hero, masked so it only emerges to the right of the type. All are seeded (identical on every load), pause off-screen, freeze to a single frame under reduced motion, and disappear below 900px. Open any of them full-size by appending the query string to index.html; ?hero=off removes it.

A — Raster index.html?hero=raster
Continuous wideband traces, one per channel, drifting right — the raw signal as the electrode sees it. At the hairline gate the waveform stops and each spike deflection carries on as a discrete accent tick on the same row: the same event, now a symbol. Gigabits of waveform in, a reduced stream out.
B — Threshold index.html?hero=threshold
One wideband trace against a dashed detection threshold. Each crossing lights a mark on the threshold line and drops an event onto the train below. The chip's first operation, shown rather than described.
C — Lattice index.html?hero=lattice
Orthogonal on-die routing with vias at the bends. The geometry never moves; the only motion is accent pulses running the routes. The quietest of the three, and the one about silicon rather than signal.
